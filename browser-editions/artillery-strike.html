Field manual · the code behind this

This is the exact same game as stage1_artillery_strike.py, the Python file in your campaign kit. Every radar message you see is an if / elif / else decision. The shell counter is a variable. The round is a while loop. And try typing banana as a coordinate — the polite refusal you get is input validation, your first piece of security code. Programs that skip that check are the ones hackers break.
